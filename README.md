# SlackInput

**当前版本：v0.3.0 · 更新日期：2026-09-15**

> 🎮 一个帮你优雅摸鱼的 Windows 小工具

上班偷偷玩游戏？老板来了手忙脚乱切桌面？SlackInput 让你按下 Xbox 手柄的 `Guide` 键，一键切换虚拟桌面，丝滑转场，毫无破绽。

## 最近更新

### v0.3.0 · 2026-09-15

- 新增「中断游戏」按钮，位于「恢复游戏」旁边，可立即暂停绑定游戏，再点击恢复继续运行。
- 游戏进程选中即绑定，Xbox 键暂停选项勾选后即时生效，无需先保存配置；保存按钮用于保留设置供下次启动使用。
- 防晕眩预览区支持点击、拖动定位，位置同步到游戏悬浮圆点；锁定后预览区和游戏画面中的圆点均不可拖动。
- 新增空心、实心、十字瞄准、叉形四种圆点内部样式，预览与游戏悬浮窗使用相同图形，样式可保存到配置文件。
- 兼容旧配置，缺少样式字段时使用空心圆环。

### v0.2.0 · 2026-09-15

**新增功能**

- 游戏进程绑定：支持按名称或 PID 筛选、刷新列表和解除绑定。
- 可选的游戏暂停：按 Xbox 键触发快捷键时，同时暂停绑定进程；默认关闭，保存配置后生效。
- 游戏恢复：提供界面与托盘恢复入口，重复暂停不叠加暂停次数，更换绑定、解除绑定和正常退出时尝试恢复游戏。
- 系统托盘：最小化后隐藏底部任务栏窗口，单击托盘图标恢复界面，右键菜单支持恢复游戏、锁定/解锁圆点和退出。
- 防晕眩圆点：中心透明的悬浮圆环，支持拖动、锁定后鼠标穿透、大小/透明度调整和一键居中。游戏暂停、退出或最小化时自动隐藏。
- 圆点配置保存：保存开关、锁定状态、大小、透明度及相对游戏窗口的位置。

**界面与修复**

- 配置界面改为深色像素风，分为快捷键、游戏进程和防晕眩圆点三个区域，保留中英文切换。
- 新增手柄与暂停符号图标，用于配置窗口、系统托盘和 EXE 文件。
- 修复无边框配置窗口无法拖动的问题：顶部图标、标题和空白区域均支持 Windows 原生拖动，兼容显示缩放，避开最小化与关闭按钮。
- 兼容旧配置；新增暂停与圆点功能默认关闭。游戏退出后清理绑定，避免误操作已被重用的进程 ID。

**验证**

- 覆盖配置兼容性、进程暂停/恢复、托盘与圆点窗口行为、标题栏拖动区域及缩放的 7 项自动化测试。
- 中英文界面已进行渲染检查。

## 它能干什么

- 监听 Xbox 手柄的 **Guide（Xbox Logo）** 按键
- 自动触发你配置的键盘快捷键（默认 `Ctrl+Win+Left`，即切换到左侧虚拟桌面）
- 支持自定义映射：`Alt+Tab`、`Ctrl+Shift+Esc`、`Win+D` 等任意组合
- 支持中英文界面
- 后台常驻，带 GUI 配置面板
- 最小化到右下角系统托盘，支持托盘恢复游戏、打开界面和退出
- 中心透明的防晕眩圆点，支持拖动、锁定、大小和透明度调整
- 深色像素风配置界面，配套窗口、托盘与 EXE 图标

## 系统要求

- **Windows 11**（当前仅支持）
- Xbox 无线手柄（通过 Xbox Wireless Adapter 或蓝牙连接）

## 快速开始

### 直接使用

从 [Releases](https://github.com/nicq-dev/xbox-guide-mapper/releases) 下载 `SlackInput-win11.exe`，双击运行即可。

### 从源码编译

```powershell
# 安装 Rust 工具链 (https://rustup.rs)
cargo build --release
# 产物在 target/release/SlackInput.exe
```

## 使用方法

1. 运行 `SlackInput.exe`，弹出配置窗口
2. 确保手柄已连接（窗口会显示连接状态）
3. 选择预设组合键，或手动输入自定义映射
4. 勾选「启用输入捕获」
5. 点击「保存」
6. 按下手柄上的 **Xbox** 键，即可触发对应快捷键

### 绑定与暂停游戏

1. 点击「选择进程」，按游戏进程名称或 PID 筛选，再点击对应进程进行绑定；可点击「刷新」更新列表。
2. 勾选「按 Xbox 键时暂停绑定游戏」后即时生效。此选项**默认关闭**，点击「保存配置」可保留设置供下次启动使用。
3. 启用输入捕获后，按 Xbox 键会触发快捷键，同时暂停绑定的游戏进程；连续触发不会叠加暂停次数。
4. 也可以点击「中断游戏」立即暂停绑定的游戏，无需按 Xbox 键；点击旁边的「恢复游戏」继续运行。更换绑定、解除绑定和正常关闭工具时也会恢复由本工具暂停的进程；恢复失败时保留原绑定供重试。

绑定只对本次运行有效，游戏退出或工具重启后需重新选择。关闭暂停选项仅阻止后续暂停，已经暂停的游戏仍可用「恢复游戏」继续。
进程列表仅显示当前有权限控制的进程，不包含本工具。暂停针对选中的单个进程，不包括子进程；工具被强制结束时无法保证自动恢复。

### 支持的按键格式

```
Ctrl+Win+Left       ← 默认：切换到左侧虚拟桌面
Ctrl+Win+Right      ← 切换到右侧虚拟桌面
Alt+Tab             ← 切换窗口
Ctrl+Shift+Esc      ← 打开任务管理器
```

支持的修饰键：`Ctrl`、`Alt`、`Shift`、`Win`  
支持的功能键：`F1`-`F24`、方向键、`Tab`、`Esc`、`Enter`、`Space`、`Home`、`End`、`PageUp`、`PageDown`  
支持的字符键：`A`-`Z`、`0`-`9`

### 托盘与窗口

- 点击右上角 `_` 最小化：主窗口从底部任务栏隐藏，程序继续在系统托盘运行。
- 单击托盘图标打开配置；右键菜单可恢复游戏、锁定/解锁圆点或退出。
- 右上角 `X` 会退出程序，并尝试恢复已暂停的游戏。按住顶部图标、标题或空白区域均可拖动窗口（最小化和关闭按钮除外）。
- 系统可能将图标收进右下角的折叠区域，可通过 Windows 的任务栏设置调整。

### 防晕眩圆点

1. 选择游戏进程，勾选「启用防晕眩圆点」（默认关闭）。
2. 游戏未被本工具暂停且游戏窗口可见时，圆环显示在游戏画面中央；中心完全透明，不会抢走游戏焦点。
3. 解锁状态下可拖动游戏画面中的白色圆点，也可以直接在启用复选框下方的预览区域点击、拖动定位；点击「锁定位置」后，两处均无法拖动，鼠标点击穿透到游戏。
4. 可选择空心、实心、十字瞄准或叉形内部样式，调整大小和不透明度，或点击「回到中心」。位置相对于游戏窗口保存，窗口移动时圆点会跟随。
5. 暂停游戏、解除绑定、游戏退出或最小化游戏后自动隐藏；恢复游戏后重新显示。

圆点调整即时生效，点击「保存配置」保留开关、锁定、样式、大小、透明度与位置。
这是普通置顶悬浮窗，适用于窗口化或无边框游戏；独占全屏或限制覆盖窗口的游戏可能无法显示。

## 配置文件

配置自动保存在 `%APPDATA%\SlackInput\SlackInput.ini`。

`pause_game_on_trigger=false` 控制 Xbox 键是否暂停绑定进程；旧配置缺少此项时按关闭处理。

圆点配置项：`focus_enabled`、`focus_locked`、`focus_style`（`ring` / `solid` / `crosshair` / `x`）、`focus_diameter`（8–36 像素）、`focus_opacity`（50–255）、`focus_x` / `focus_y`（相对于游戏窗口的 0–1 坐标）。旧配置会自动使用默认值。

## 开发验证

`cargo test` 包含配置兼容性、真实临时进程暂停/恢复，以及原生托盘隐藏/恢复、圆点拖动、锁定穿透和暂停隐藏测试。
Debug 构建可通过 `SLACKINPUT_UI_SNAPSHOT` 指定路径导出应用自身的渲染截图并退出；`SLACKINPUT_UI_LANGUAGE=zh-CN` 或 `en` 切换截图语言。此模式关闭输入捕获且不保存配置。

图标生成信息见 [assets/README.md](assets/README.md)。

## 发布到 GitHub

在项目根目录使用 PowerShell 运行 `release.ps1`。需要已安装 Rust、Git 和 GitHub CLI（`gh`），并通过 `gh auth login` 登录具有仓库发布权限的账号。

发布前先提交所有要发布的改动，并推送到 GitHub。脚本会编译本地工作区，但不会自动提交或推送代码；新标签默认指向远端默认分支，因此应确保该分支已包含本次发布的提交。

```powershell
# 提交并推送代码后运行：自动从 Cargo.toml 读取版本，当前为 v0.3.0
.\release.ps1

# 也可以先创建草稿，在 GitHub 检查后再正式发布
.\release.ps1 -Draft

# 仅生成发布说明，检查中文编码，不编译、不上传
.\release.ps1 -NotesOnly
```

脚本会运行 `cargo build --release`，将产物复制为 `dist/SlackInput-win11.exe`，从上一个标签之后的 Git 提交生成发布说明，并创建带 EXE 附件的 GitHub Release。`-TagName` 可显式指定标签，例如 `.\release.ps1 -TagName v0.3.0`。

脚本显式按 UTF-8 读取 Git 日志，将说明保存为 `dist/release-notes.md`，并通过 `gh --notes-file` 上传，兼容 Windows PowerShell 5.1 和 PowerShell 7 的中文编码。说明只包含已提交的 Git 记录；已发布的乱码说明需要编辑现有 Release，重新运行创建命令不会修复它。

## 注意事项

- Xbox Game Bar、Steam Input 或某些厂商驱动可能会拦截 Guide 键，导致本工具收不到按键事件。如遇此情况，请先关闭相关软件。
- 当前仅支持 Xbox Wireless Controller（VID: 045E, PID: 02E0）通过 Raw Input 上报 Guide 键。
- 开启「调试日志」可查看原始 HID 数据，方便排查问题。
