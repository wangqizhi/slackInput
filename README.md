# SlackInput

**当前版本：v0.3.5 · 更新日期：2026-09-18**

> 🎮 一个帮你优雅摸鱼的 Windows 小工具

上班偷偷玩游戏？老板来了手忙脚乱切桌面？SlackInput 让你按下 Xbox 手柄的 `Guide` 键，一键切换虚拟桌面，丝滑转场，毫无破绽。

## 最近更新

## 它能干什么

- 监听 Xbox 手柄的 **Guide（Xbox Logo）** 按键
- 自动触发你配置的键盘快捷键（默认 `Ctrl+Win+Left`，即切换到左侧虚拟桌面）
- 支持自定义映射：`Alt+Tab`、`Ctrl+Shift+Esc`、`Win+D` 等任意组合
- 支持中英文界面
- 后台常驻，配备 480×560 的小组件界面和上下排列的圆角暂停／恢复按钮
- 最小化到右下角系统托盘，支持托盘恢复游戏、打开界面和退出
- 记住上次绑定的游戏进程，默认自动加载；进程列表置顶高亮，支持手动重新绑定
- 防晕眩圆点支持四种样式、拖动、锁定、大小和透明度调整，按游戏自动保存配置
- 深色像素风配置界面，配套窗口、托盘与 EXE 图标

## 系统要求

- **Windows 11**（当前仅支持）
- Xbox 无线手柄（通过 Xbox Wireless Adapter 或蓝牙连接）

## 快速开始

### 直接使用

从 [Releases](https://github.com/wangqizhi/slackInput/releases) 下载 `SlackInput-win11.exe`，双击运行即可。

### 从源码编译

```powershell
# 安装 Rust 工具链 (https://rustup.rs)
cargo build --release
# 产物在 target/release/SlackInput.exe
```

## 使用方法

1. 运行 `SlackInput.exe`，弹出配置窗口
2. 确保手柄已连接（窗口会显示连接状态）
3. 在「快捷键」页选择预设组合键，或手动输入、捕获自定义映射
4. 切换到「设置」页，勾选「启用输入捕获」
5. 在「设置」页点击「保存配置」
6. 按下手柄上的 **Xbox** 键，即可触发对应快捷键

### 界面页签

- **游戏**：显示绑定进程和运行状态，提供上下排列的「中断游戏」「恢复游戏」圆角按钮，以及选择进程、解除绑定操作。暂停后恢复按钮变绿，方便继续游戏。
- **快捷键**：设置常用映射和键盘触发键，支持捕获、清空与垂直滚动。下方预留按键宏区域，当前尚未实现宏编辑或执行。
- **设置**：集中放置所有勾选项、防晕眩圆点调整、保存配置、恢复默认与调试日志入口；内容较多时可上下滚动。恢复默认保留上次进程记忆及圆点配置。

### 键盘触发

在「快捷键」页的「键盘触发键」填写 `F8`、`Ctrl+Alt+Q` 等单键或组合键，然后到「设置」页点击「保存配置」生效，留空则关闭。默认关闭，Xbox 键仍然可用。

松开触发键及其修饰键后，会执行当前配置的切屏快捷键；勾选「Xbox / 键盘触发时暂停游戏」并绑定进程后，也会暂停游戏。需启用输入捕获。长按不会重复触发；快捷键被其他程序占用时会提示注册失败，并保留原键盘触发设置。

### 绑定与暂停游戏

1. 在「游戏」页点击「选择进程」，按游戏进程名称或 PID 筛选，再点击对应进程进行绑定；可点击「刷新」更新列表。上一次绑定的进程会排在列表最前面并高亮显示，方便重新绑定同一个游戏。
2. 在「设置」页勾选「Xbox / 键盘触发时暂停游戏」后即时生效。此选项**默认关闭**，点击「保存配置」可保留设置供下次启动使用。
3. 启用输入捕获后，按 Xbox 键会触发快捷键，同时暂停绑定的游戏进程；连续触发不会叠加暂停次数。
4. 也可以点击「中断游戏」立即暂停绑定的游戏，无需按 Xbox 键；暂停后，下方「恢复游戏」按钮变绿，点击即可继续运行。更换绑定、解除绑定和正常关闭工具时也会恢复由本工具暂停的进程；恢复失败时保留原绑定供重试。

工具会记住上次绑定的进程名并在列表中置顶。默认每秒后台检查并自动加载仍在运行的同名进程，游戏晚于工具启动或工具最小化时也有效；也可在「设置」页通过「自动加载上次的进程」选项关闭自动加载，设置即时保存。开启选项时会立即尝试加载。手动解除绑定后暂停后台自动加载，重新打开或刷新进程列表、重新开启自动加载选项可恢复。关闭暂停选项仅阻止后续暂停，已经暂停的游戏仍可用「恢复游戏」继续。
进程列表仅显示当前有权限控制的进程，不包含本工具。暂停针对选中的单个进程，不包括子进程；工具被强制结束时无法保证自动恢复。

### 支持的按键格式

```
Ctrl+Win+Left       ← 默认：切换到左侧虚拟桌面
Ctrl+Win+Right      ← 切换到右侧虚拟桌面
Alt+Tab             ← 切换窗口
Ctrl+Shift+Esc      ← 打开任务管理器
```

支持的修饰键：`Ctrl`、`Alt`、`Shift`、`Win`  
支持的功能键：`F1`-`F24`、方向键、`Tab`、`Esc`、`Enter`、`Space`、`Home`、`End`、`PageUp`、`PageDown`  
支持的字符键：`A`-`Z`、`0`-`9`

### 托盘与窗口

- 点击右上角 `_` 最小化：主窗口从底部任务栏隐藏，程序继续在系统托盘运行。
- 单击托盘图标打开配置；右键菜单可恢复游戏、锁定/解锁圆点或退出。
- 右上角 `X` 会退出程序，并尝试恢复已暂停的游戏。按住顶部图标、标题或空白区域均可拖动窗口（最小化和关闭按钮除外）。
- 系统可能将图标收进右下角的折叠区域，可通过 Windows 的任务栏设置调整。

### 防晕眩圆点

1. 在「游戏」页选择游戏进程，再到「设置」页勾选「启用防晕眩圆点」（默认关闭）。圆点设置区会显示当前游戏进程名。
2. 游戏未被本工具暂停且游戏窗口可见时，圆点显示在已保存的位置，默认居中；默认空心圆环的中心透明，不会抢走游戏焦点。
3. 解锁状态下可拖动游戏画面中的白色圆点，也可以直接在启用复选框下方的预览区域点击、拖动定位；点击「锁定位置」后，两处均无法拖动，鼠标点击穿透到游戏。
4. 可选择空心、实心、十字瞄准或叉形内部样式，调整大小和不透明度，或点击「回到中心」。位置相对于游戏窗口保存，窗口移动时圆点会跟随。
5. 暂停游戏、解除绑定、游戏退出或最小化游戏后自动隐藏；恢复游戏后重新显示。

圆点调整即时生效并自动保存，无需点击「保存配置」，包括预览拖动、游戏画面内拖动以及托盘锁定／解锁。已绑定游戏按进程名分别记忆（不区分大小写），游戏重启后 PID 改变也能加载，同名进程共享配置。未绑定时保存为默认配置；尚无独立配置的游戏首次绑定时继承默认值。
这是普通置顶悬浮窗，适用于窗口化或无边框游戏；独占全屏或限制覆盖窗口的游戏可能无法显示。

## 配置文件

通用配置和默认圆点配置保存在 `%APPDATA%\SlackInput\SlackInput.ini`。快捷键映射、键盘触发键等通过「设置」页的「保存配置」保存。

`pause_game_on_trigger=false` 控制 Xbox / 键盘触发时是否暂停绑定进程；默认关闭，切换即时生效，保存配置后可在下次启动时保留。

`last_process` 记录上次绑定的进程名称（如 `game.exe`），选中进程时立即保存，用于进程列表置顶以及自动加载。`auto_load_process` 默认开启，修改后立即保存；没有有效绑定时每秒检查上次的进程。保存进程记忆或自动加载开关不会顺带保存其他未保存的通用设置。

每个游戏的圆点配置保存在 `%APPDATA%\SlackInput\games\` 下的独立 `.ini` 文件中，文件名为小写进程名 UTF-8 字节的十六进制编码。文件仅包含圆点设置；修改某个游戏不会覆盖其他游戏或通用配置中的默认圆点设置。

圆点配置项：`focus_enabled`、`focus_locked`、`focus_style`（`ring` / `solid` / `crosshair` / `x`）、`focus_diameter`（8–36 像素）、`focus_opacity`（50–255）、`focus_x` / `focus_y`（相对于游戏窗口的 0–1 坐标）。旧配置会自动使用默认值。

## 开发验证

`cargo test` 包含配置兼容性、按进程名生成配置路径、游戏圆点配置读写与隔离、真实临时进程暂停/恢复，以及原生托盘隐藏/恢复、圆点拖动、锁定穿透和暂停隐藏测试。
Debug 构建可通过 `SLACKINPUT_UI_SNAPSHOT` 指定路径导出应用自身的渲染截图并退出；`SLACKINPUT_UI_LANGUAGE=zh-CN` 或 `en` 切换截图语言，`SLACKINPUT_UI_PICKER=1` 额外展开进程选择窗口，用于检查置顶与高亮效果。`SLACKINPUT_UI_TAB=0` / `1` / `2` 分别选择游戏、快捷键、设置页；`SLACKINPUT_UI_SCROLL_BOTTOM=1` 检查页签底部内容。此模式关闭输入捕获且不保存配置。

图标生成信息见 [assets/README.md](assets/README.md)。

## 发布到 GitHub

在项目根目录使用 PowerShell 运行 `release.ps1`。需要已安装 Rust、Git 和 GitHub CLI（`gh`），并通过 `gh auth login` 登录具有仓库发布权限的账号。

发布前先提交所有要发布的改动，并推送到 GitHub。脚本会编译本地工作区，但不会自动提交或推送代码；新标签默认指向远端默认分支，因此应确保该分支已包含本次发布的提交。

```powershell
# 提交并推送代码后运行：自动从 Cargo.toml 读取版本，当前为 v0.3.5
.\release.ps1

# 也可以先创建草稿，在 GitHub 检查后再正式发布
.\release.ps1 -Draft

# 仅生成发布说明，检查中文编码，不编译、不上传
.\release.ps1 -NotesOnly
```

脚本会运行 `cargo build --release`，将产物复制为 `dist/SlackInput-win11.exe`，从上一个标签之后的 Git 提交生成发布说明，并创建带 EXE 附件的 GitHub Release。`-TagName` 可显式指定标签，例如 `.\release.ps1 -TagName v0.3.5`。

脚本显式按 UTF-8 读取 Git 日志，将说明保存为 `dist/release-notes.md`，并通过 `gh --notes-file` 上传，兼容 Windows PowerShell 5.1 和 PowerShell 7 的中文编码。说明只包含已提交的 Git 记录；已发布的乱码说明需要编辑现有 Release，重新运行创建命令不会修复它。

## 注意事项

- Xbox Game Bar、Steam Input 或某些厂商驱动可能会拦截 Guide 键，导致本工具收不到按键事件。如遇此情况，请先关闭相关软件。
- 当前仅支持 Xbox Wireless Controller（VID: 045E, PID: 02E0）通过 Raw Input 上报 Guide 键。
- 开启「调试日志」可查看原始 HID 数据，方便排查问题。
