# SlackInput icon

Generated with the built-in imagegen tool. The gamepad and pause bars match the controller shortcut and game suspension features; the stepped outline matches the pixel interface.

- `icon-source.png`: original generated asset.
- `icon.png`: 256 × 256 PNG used by the UI, main window and notification-area icon.
- `app.ico`: Windows executable icon, embedded at build time through `winresource`.

Only resizing and ICO packaging were applied after generation.

## Final generation prompt

> Use case: logo-brand. Create a single pixel-art application icon for SlackInput, a Windows Xbox controller shortcut, game pause and focus-dot utility. A bold mint-green pixel gamepad silhouette with a small clearly readable pause symbol made of two cream vertical pixel bars at its center, on a dark midnight navy square tile with stepped pixel corners and a thin teal pixel border. Flat crisp 16-bit pixel art, strict square pixel grid, no gradients, no blur, no text, no letters, no watermark. Simple strong silhouette readable at 16x16 and 32x32 tray icon size. One centered icon filling 90% of the square, symmetric front view, no extra objects or mockup, square 1024x1024 image.
